INF512-Unidad1-POO

Descripción del proyecto

Este proyecto corresponde a la actividad de la Unidad 1 de la asignatura INF512 y tiene como finalidad aplicar los fundamentos de la Programación Orientada a Objetos (POO) utilizando el lenguaje C#.

En el proyecto se desarrolla una clase que contiene atributos y métodos, permitiendo comprender de manera práctica cómo se organiza un programa utilizando el enfoque orientado a objetos.

Objetivo

El objetivo es aplicar los conceptos básicos de la Programación Orientada a Objetos, especialmente:

- Clases.
- Objetos.
- Atributos.
- Métodos.
- Constructor.
- Encapsulamiento.

Archivo principal

El proyecto contiene el archivo:

Producto.cs

Este archivo contiene una clase "Producto" con sus respectivos atributos, constructor y métodos.

Los atributos representan el estado del producto, mientras que los métodos representan las acciones que el objeto puede realizar.

Conceptos de POO aplicados

Clase

La clase "Producto" funciona como un modelo que permite crear objetos que representan productos.

Objeto

Un objeto es una instancia de la clase "Producto" y contiene valores específicos para sus atributos.

Estado

El estado del producto está determinado por los valores de sus atributos, como su nombre, precio y cantidad.

Comportamiento

El comportamiento está representado por los métodos de la clase, mediante los cuales se pueden realizar operaciones sobre el producto.

Encapsulamiento

El encapsulamiento permite proteger los datos internos de la clase utilizando atributos privados y métodos públicos para controlar el acceso y las modificaciones.

Control de versiones

Para este proyecto se utiliza Git como sistema de control de versiones. Git permite registrar los cambios realizados en el código mediante commits.

Se realizarán como mínimo tres commits con mensajes claros y descriptivos. Esto permite mantener un historial organizado del proyecto y facilita identificar los cambios realizados.

Reflexión

La realización de esta actividad me permitió comprender de una manera más práctica cómo funciona la Programación Orientada a Objetos. Al crear la clase "Producto", pude observar que los atributos representan las características y el estado de un objeto, mientras que los métodos representan las acciones que este puede realizar.

También comprendí la importancia del encapsulamiento para proteger los datos y mantener un mejor control sobre las modificaciones que pueden realizarse en un objeto. Además, el uso de Git me permitió conocer la importancia de llevar un historial de los cambios realizados en un proyecto.

Considero que esta práctica es importante porque permite relacionar los conceptos teóricos de la POO con un ejemplo desarrollado en C#, facilitando la comprensión de cómo se pueden construir programas organizados y fáciles de mantener.
